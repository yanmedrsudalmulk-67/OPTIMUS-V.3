# Implementation contract

Shared domain types live in `packages/shared/src/index.ts`. UI imports that file by relative paths. All JSON endpoints are under `/api` on API port 4001; Next proxies `/api/:path*`, `/uploads/:path*`, and `/socket.io/:path*`. Successful REST bodies are the data directly, errors `{error:string}`.

Authentication: POST `/api/auth/login` `{username,password}` -> `{id,username}` sets HttpOnly session cookie. GET `/api/auth/me` -> `{id,username}` or 401; POST `/api/auth/logout` clears cookie. All other admin REST and host socket events require this session. Public GET `/api/health`, GET `/api/rooms/:code` returns sanitized RoomState.

Admin REST: GET `/api/dashboard` -> DashboardData; GET `/api/packages` -> QuestionPackage[] (with questions); POST `/api/packages` `{name,description}`; PATCH/DELETE `/api/packages/:id`; POST `/api/questions` question fields without id; PATCH/DELETE `/api/questions/:id`; POST `/api/questions/:id/duplicate`; POST `/api/questions/import` `{rows:object[],commit:boolean}` -> `{valid:Question[],errors:{row:number,error:string}[],imported:number}`; GET `/api/questions/export?format=csv|xlsx&packageId=...` downloadable; GET `/api/questions/template?format=csv|xlsx` downloadable. POST `/api/uploads` multipart `image` -> `{url}`. GET/PUT `/api/settings` -> GameSettings. GET `/api/matches` -> RoomState[]; GET `/api/matches/:id` -> RoomState (+optional answers); POST `/api/matches` `{title,teamAName,teamBName,packageId,settings:Partial<GameSettings>}` -> RoomState; GET `/api/leaderboard` -> `{id,name,team,score,correctCount,power,matches}[]`. Optional POST `/api/auth/password` `{currentPassword,password}`.

Socket.IO same-origin connection through Next, path `/socket.io`, with credentials. `room:watch` `{code}` -> ack RoomState and subscribes. `room:join` `{code,name,team,characterId,token?}` -> ack JoinResult; persist returned token per room in localStorage. Socket auth accepts `{playerToken}` for reconnect; use join with saved token for explicit restoration. Rejoin does not create duplicates. `player:set-ready` `{code,ready}`; `player:select-character` `{code,characterId,name?}`; `player:submit-answer` `{code,questionId,answer:number}`; `room:leave` `{code}`. Every event uses ack `{ok,data?,error?}`. Broadcasts `room:state` RoomState after changes. All player actions derive identity from token, not caller-supplied player ID.

Host events: `host:start-match`, `host:pause-match`, `host:resume-match`, `host:next-question`, `host:end-match`, `host:reset-match`, `host:lock-lobby` `{code,locked?}`. `host:move-player` `{code,playerId,team}`, `host:kick-player` `{code,playerId}`. Auth session from cookie, never trust payload role. Match starts only with six connected ready players (3 per team). No answer key before reveal, including REST/watch/history. Phase timers controlled by server; pause preserves remaining time; each round scored once, duplicate answers rejected. DB stores room state, question snapshots, answers, rounds. Restart restores paused active rooms safely.

Frontend components: arena agent exports `Arena` default from `apps/web/components/arena/Arena.tsx` accepting `{state?:RoomState|null,preview?:boolean,theme?:'hospital'|'fantasy',quality?:Quality,className?:string}` and `CharacterPreview` default from `.../CharacterPreview.tsx` accepting `{characterId:string,team?:Team}`. Client-only lazy import via next/dynamic ssr:false. UI agent for admin owns `apps/web/app/admin/**` and `components/admin/**`. Player agent owns `app/join/**`, `app/lobby/**`, `app/play/**`, `app/display/**` and `components/game/**`. Root owns layout, global styles, landing, `lib/api.ts`, `lib/socket.ts`, `lib/audio.ts`, project setup, tests/docs. Agents may add their own CSS files; do not edit global files.

Root utility exports: `api<T>(path:string, options?:RequestInit):Promise<T>` prepends `/api` and JSON content-type when appropriate; `getSocket():Socket` singleton; `emit<T>(event:string,payload:unknown):Promise<T>` rejects ack error. Audio `playSound(kind:string)` and `setMuted(boolean)`. Common classes available: button (`btn`, `btn-primary`, `btn-secondary`, `btn-danger`, `btn-small`), `input`, `select`, `card`, `muted`, `eyebrow`, `badge`, `badge-green`, `badge-blue`, `empty-state`, `error-message`, `page-heading`, `field`, `form-grid`, `table-wrap`, `data-table`, `modal-backdrop`, `modal`, `section-title`, `spinner`. Root UI tone: light warm gray #f5f6f7, white cards, navy #172d32, emerald #168e72, royal blue #416ed9, warm yellow #edb74e. Main app text Indonesian, product titles English permitted.
