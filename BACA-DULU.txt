CARA MENJALANKAN GAME:
1. Klik dua kali MULAI-WINDOWS.bat untuk menjalankan game.
2. Game otomatis terbuka di browser: http://localhost:3005
3. Akun admin otomatis terbuka di AKUN-ADMIN.txt (Username: admin, Password: admin12345678).
4. Untuk berhenti, cukup tutup jendela terminal atau klik dua kali HENTIKAN-WINDOWS.bat.


CARA INTEGRASI DENGAN GITHUB (CHATGPT):
- Jika Anda meminta ChatGPT memperbarui fitur/menu game di GitHub:
  Cukup klik dua kali: UPDATE-DARI-GITHUB.bat
  Perubahan kode terbaru dari GitHub akan otomatis ditarik dan disinkronkan ke komputer lokal ini.
- Jika Anda ingin mengirim perubahan lokal ke GitHub:
  Cukup klik dua kali: PUSH-KE-GITHUB.bat
