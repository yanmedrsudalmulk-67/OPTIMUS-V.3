MEDICAL TUG OF WAR - SQLITE - PORT 3005

WINDOWS (64-bit)
1. Extract All ZIP ke folder BARU yang tetap, misalnya Documents\Medical-Tug-SQLite.
   Jangan campurkan dengan konfigurasi PostgreSQL dari versi sebelumnya.
2. Klik dua kali MULAI-WINDOWS.bat. Jangan jalankan dari dalam ZIP.
3. Tunggu pemasangan pertama. Internet diperlukan untuk mengunduh Node.js
   portabel (jika Node 24 belum tersedia) dan dependensi. Tidak perlu Docker.
4. Shortcut Medical Tug of War dibuat otomatis di Desktop komputer Anda.
5. Browser terbuka setelah game siap. Akun login ada di AKUN-ADMIN.txt.
6. Untuk berikutnya, klik shortcut Desktop. Jangan pindahkan folder game;
   jika dipindah, jalankan MULAI-WINDOWS.bat lagi untuk memperbarui shortcut.
7. Berhenti: tekan Ctrl+C di jendela game. Jangan jalankan dua salinan bersamaan.

DATABASE
Semua tabel kuis, admin, room, jawaban, skor, dan pengaturan ada di medical.db
pada folder game. Jangan hapus file ini. Gambar unggahan tersimpan terpisah.
Saat memindahkan game, hentikan dahulu dan ikut salin medical.db, .env,
AKUN-ADMIN.txt serta apps/realtime-server/uploads. Jangan bagikan akun privat.

MAC / LINUX / ANTIGRAVITY
Pasang Node.js 24. Jalankan: npm run local
macOS juga dapat menjalankan MULAI-MAC.command.

CATATAN
Port browser 3005; API internal 4001. Kedua port harus tersedia.
Windows memakai Node x64. Pada Windows ARM dibutuhkan emulasi x64.
Peluncur Windows dan shortcut belum diuji pada OS Windows dari cloud ini.
Baca README.md untuk akses HP lewat LAN, backup, dan pengembangan.
